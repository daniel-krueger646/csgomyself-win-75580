## About CSGOmyself

CSGOmyself is a browser-based first-person shooter built with WebGL and shaped around fast, familiar FPS combat. It is designed for players who want a lightweight game experience that runs in the browser without needing a separate installer or a traditional multiplayer backend.

The project supports solo play against bots as well as a 1v1 peer-to-peer mode powered by WebRTC. That makes it useful for quick matches, local-style play sessions, and scenarios where a serverless setup is preferred.

---

## Features

- WebGL-powered browser FPS experience
- 10 bot match mode for solo play
- 1v1 peer-to-peer multiplayer through WebRTC
- No dedicated server required
- No internet connection required for supported play modes
- Realistic recoil patterns for weapon handling
- Movement mechanics including crouch, walk, and jump
- On-screen HUD with health, ammo, kill feed, and weapon slots
- Bullet tracers for more readable combat feedback
- Radar display for situational awareness
- Bot AI behavior that can patrol, chase, and flank
